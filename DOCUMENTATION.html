Rider App — API Reference

Rider app in endpoints se backend se communicate karti hai

Method Endpoint Auth Description Request Body / Params
POST /api/rider/auth/login Public Rider login — mobile + password se JWT token milta hai { mobile, password }
GET /api/rider/profile 🔒 Rider JWT Apna profile dekho (name, vehicle, store, stats) —
PUT /api/rider/profile 🔒 Rider JWT Name, vehicleType, vehicleNumber update karo { name, vehicleType, vehicleNumber }
PATCH /api/rider/profile/toggle-online 🔒 Rider JWT Online/Offline toggle karo (admin ko dikhta hai card pe) —
PATCH /api/rider/profile/password 🔒 Rider JWT Password change karo { currentPassword, newPassword }
GET /api/rider/orders?filter=active 🔒 Rider JWT Assigned orders dekho ?filter=active | done
GET /api/rider/orders/:id 🔒 Rider JWT Single order detail (items, customer, timeline) —
PATCH /api/rider/orders/:id/status 🔒 Rider JWT Order status update karo (sirf out_for_delivery ya delivered) { status, note? }
GET /api/rider/orders/earnings 🔒 Rider JWT Earnings summary (total deliveries, total earned, today's count) —
PATCH /api/admin/riders/:id/set-password 🔒 Admin JWT Admin rider ka password reset kar sakta hai { password }
PATCH /api/admin/orders/:id/assign-rider 🔒 Admin JWT Order pe rider assign karo (ya null = unassign) { riderId: number | null }
Rider Model Fields (Database):
IDENTITY
id INT PK
name VARCHAR(100)
mobile VARCHAR(15) UNIQUE
password VARCHAR(255) bcrypt
VEHICLE + STATUS
vehicleType ENUM bike|scooter|cycle|other
vehicleNumber VARCHAR(20)
isOnline BOOLEAN default false
status ENUM active|inactive|suspended
STATS + RELATIONS
storeId FK → dark_stores
rating DECIMAL(3,2) default 5.00
totalDeliveries INT default 0
totalEarnings INT default 0 (paise)
🔒
Security: Rider JWT token mein role: "rider" hota hai — rider sirf /api/rider/... endpoints access kar sakta hai. Admin endpoints par rider ka token reject ho jaata hai. Rider sirf apne assigned orders ke status update kar sakta hai (out_for_delivery aur delivered only).
